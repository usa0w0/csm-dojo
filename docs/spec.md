# 仕様

元の issue: [usa0w0/workbench#10](https://github.com/usa0w0/workbench/issues/10)（2026-10-08 時点の内容を写した）。以後はこのファイルを正とする。

## 目的

認定スクラムマスター（CSM）試験を 10/11（日）か 10/12（月）に受けるユーザーと友人が、スマホで模擬問題を繰り返し解いて合格ラインに届くようにする。

## 完了条件

- [ ] 試験の形式、出題範囲、問題の出典を調べた結果が `docs/research.md` にまとまっている（調べた日と参照先の URL 付き）
- [ ] スマホのブラウザーで URL を開くと、ログインなしで四択の問題が1問ずつ出て、答えられる
- [ ] 答えた直後に、正誤、解説、根拠（スクラムガイドの該当箇所）が表示される
- [ ] 分野を選んで出題できる
- [ ] 間違えた問題だけを出題できる
- [ ] 解答の履歴と分野別の正答率が見られ、ブラウザーを閉じて開き直しても残っている
- [ ] 本番と同じ形式の模擬試験（50問、60分、37問正解で合格）ができ、終了時に得点と合否が出る
- [ ] 作り置きの問題が200問以上あり、すべてに解説と根拠が付いている
- [ ] 10/10（土）中に、上のすべてがスマホの実機で確認できている

## やらないこと

- アカウント、ログイン、端末をまたいだ履歴の同期
- 解くたびに AI で問題を作ること（問題は作り置きする）
- 講座で配られた資料を問題や解説に使うこと
- CSM 以外の資格への対応

## 制約

- サーバーを持たない静的なサイトにする。API の利用料がかからない構成にする
- GitHub Pages で公開する。URL を知っている人なら誰でも開ける形でよい。リポジトリも公開にする
- スマホのブラウザーで使う前提の画面にする
- 問題と解説は、公開されている資料（スクラムガイドなど）だけを元に作る。何を元にするかは、最初の調査で決める（結果は `docs/research.md`）
- 期限は 10/10（土）。調査と問題作りに時間を使えるよう、機能は完了条件の範囲に絞る

## Mode

`delegate`

## 前提

- 対象は Scrum Alliance の CSM 試験。形式は50問、60分、37問正解（74%）で合格
- 問題と画面は日本語にする
- 問題数は200問以上にする
- 履歴はブラウザーの中（localStorage）に保存する。端末ごとに別になる
- 「過去問道場」に当たる機能は、分野別の出題、間違えた問題の復習、履歴と正答率、模擬試験の4つとする
- スクラムガイドは CC BY-SA 4.0 で公開されているので、出典を示して引用する
